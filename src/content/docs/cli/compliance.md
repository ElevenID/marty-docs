## Commands

### `marty compliance list`

List all compliance profiles.

```bash
marty compliance list [--json]
```

### `marty compliance inspect`

Inspect a compliance profile.

```bash
marty compliance inspect <profile-id> [--json]
```

### `marty compliance create`

Create a new compliance profile.

```bash
marty compliance create [options] [--json]
```
