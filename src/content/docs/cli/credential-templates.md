Credential templates define the schema, format, and claims for issued credentials.

## Commands

### `marty ct list`

List all credential templates.

```bash
marty ct list [--json]
```

### `marty ct inspect`

Inspect a credential template.

```bash
marty ct inspect <template-id> [--json]
```

### `marty ct create`

Create a new credential template.

```bash
marty ct create [options] [--json]
```
