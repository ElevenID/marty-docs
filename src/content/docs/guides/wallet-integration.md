## Overview

ElevenID supports credential exchange with wallets that implement:

- **OID4VCI** — for receiving issued credentials
- **OID4VP** — for presenting credentials to verifiers
- **ISO 18013-5** — for mDoc-based mobile documents

## Supported wallets

ElevenID has been tested with wallets that support the following SDK flavors:

- **SpruceID** SDK
- **Google CredentialManager** (Android)
- **Apple Wallet** (iOS)
- Standard OID4VCI/OID4VP implementations
